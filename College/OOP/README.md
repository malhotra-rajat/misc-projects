# Object-oriented programming

Historical sources from Third-semester OOPS lab. Exact-byte duplicates within this collection are stored once; their original locations are listed in `archive/provenance.json` at the repository root. Some original source files use a `.txt` extension. Source comments/credits are retained, including reference material by other authors.

The tested nonempty C/C++ sources do not pass unchanged macOS compiler syntax checks. Common dependencies include Turbo C++ headers, DOS console functions and Borland graphics; some also contain original code errors. Use a compatible historical compiler or create a separate compatibility version. See the repository's `RUNNING.md`. No compiler binaries or personal result documents are included.
